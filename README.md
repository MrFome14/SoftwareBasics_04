## Общее описание решения

В ходе лабораторной работы был разработан модуль `geometric_lib`, предназначенный для вычисления площадей и периметров четырех простейших геометрических фигур:
**круга, квадрата, прямоугольника и треугольника.**
 Решение состоит из четырёх файлов: `circle.py`, `rectangle.py`, `square.py` и `triangle.py`.

Каждый файл содержит две функции: `area()`, вычисляющую площадь соответствующей фигуры, и `perimeter()`, вычисляющую её периметр или длину окружности.

Для всех функций добавлены _docstring_, содержащие описание назначения функции, входных параметров, возвращаемого значения и примеры вызова с результатами.

Для автоматического создания документации используется инструмент `pydoc-markdown`, который извлекает описания из исходного кода и формирует документацию в формате Markdown. Полученная документация лежит в папке **docs**.

_Структура папки docs:_

- functions.md - документация функций вычисления площадей и периметров геометрических фигур, сформированная с помощью `pydoc-markdown`.

- history.md - история изменений проекта с хешами соответствующих коммитов Git, за исключением последней записи.
