## 1. Цели и задачи тестирования

Основной целью тестирования является проверка корректности работы функций вычисления площадей и периметров геометрических фигур, реализованных в проекте `geometric_lib`.

Для достижения поставленной цели необходимо решить следующие задачи:

- Проверить правильность вычисления площадей геометрических фигур.
- Проверить правильность вычисления периметров геометрических фигур.
- Проверить корректность обработки различных входных значений, включая нулевые и дробные числа.
- Убедиться в соответствии фактических результатов вычислений ожидаемым значениям.
- Автоматизировать процесс проверки с использованием модуля `unittest`.

## 2. Описание тестируемого продукта

`geometric_lib` — программный модуль на языке Python, предназначенный для выполнения математических вычислений, связанных с основными геометрическими фигурами.

Проект состоит из четырёх Python-файлов:

- `circle.py` — содержит функции вычисления площади круга и длины окружности.
- `rectangle.py` — содержит функции вычисления площади и периметра прямоугольника.
- `square.py` — содержит функции вычисления площади и периметра квадрата.
- `triangle.py` — содержит функции вычисления площади и периметра треугольника.

Каждый модуль предоставляет две функции: `area()` и `perimeter()`. Функции принимают необходимые геометрические параметры и возвращают результат вычисления.

## 3. Область тестирования

В рамках лабораторной работы тестированию подлежат все восемь функций проекта:

| Модуль | Тестируемые функции |
|---|---|
| `circle.py` | `area(r)`, `perimeter(r)` |
| `rectangle.py` | `area(a, b)`, `perimeter(a, b)` |
| `square.py` | `area(a)`, `perimeter(a)` |
| `triangle.py` | `area(a, h)`, `perimeter(a, b, c)` |

Проверке подлежат следующие аспекты:

- Корректность математических вычислений.
- Обработка нулевых значений параметров.
- Корректность вычислений при использовании целых чисел.
- Корректность вычислений при использовании вещественных чисел.

## 4. Стратегия тестирования

Для проверки проекта используется метод модульного тестирования (Unit Testing) с применением стандартного модуля Python `unittest`.

Для каждого Python-модуля создаётся отдельный файл с тестами. Тестовые классы наследуются от `unittest.TestCase`, а проверка результатов осуществляется с помощью встроенных методов `assert`.

В процессе тестирования используются следующие подходы:

- **Проверка граничных значений:** тестирование функций с нулевыми параметрами.
- **Проверка стандартных значений:** тестирование функций на типичных наборах входных данных.
- **Проверка вещественных значений:** проверка корректности вычислений с дробными числами.
- **Сравнение результатов:** сопоставление фактических результатов работы функций с заранее рассчитанными ожидаемыми значениями.

Для сравнения целочисленных результатов используется `assertEqual()`, для вещественных результатов — `assertAlmostEqual()`.

## 5. Критерии приёмки

Тестирование считается успешно завершённым при выполнении следующих условий:

- Все тестируемые функции возвращают ожидаемые результаты.
- Все разработанные автоматические тесты успешно проходят.
- Отсутствуют необработанные ошибки при выполнении тестовых сценариев.
- Тесты запускаются с использованием стандартного модуля `unittest`.
